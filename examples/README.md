# 示例代码 (Examples)

本目录包含 MediaCrawler 各种功能的示例代码。

This directory contains example code for various MediaCrawler features.

## 可用示例 (Available Examples)

### 1. checkpoint_demo.py - 断点续传功能演示

演示如何使用断点续传功能。

Demonstrates how to use the checkpoint resume feature.

**运行方式 (How to run):**

```bash
python examples/checkpoint_demo.py
```

**功能演示 (Features demonstrated):**
- 基本的checkpoint保存和加载
- 多关键词checkpoint管理
- 中断恢复场景模拟

**交互式菜单选项:**
1. 基本使用 - 展示save/load/clear操作
2. 多关键词管理 - 展示同时管理多个checkpoint
3. 中断恢复模拟 - 模拟真实的中断和恢复场景
4. 运行全部演示 - 依次运行所有演示
0. 退出
